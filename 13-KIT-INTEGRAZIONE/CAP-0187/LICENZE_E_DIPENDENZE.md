# CAP-0187 — Licenze e dipendenze

Ricerca funzionale E0: nessuna licenza conferisce qui una autorizzazione automatica di riuso commerciale del codice.

## Fonti e classificazione disponibile
- dendronhq/dendron: REST Apache-2.0; license per source file must be independently verified
- Laverna/laverna: REST MPL-2.0; license per source file must be independently verified
- vnotex/vnote: REST LGPL-3.0; license per source file must be independently verified
- sorenwacker/nodus: RESTRICTED_SOURCE_AVAILABLE: Nodus License: uso personale o commerciale interno, redistribuzione vietata senza autorizzazione
- Zettlr/Zettlr: REST GPL-3.0; license per source file must be independently verified

Verificare file, directory, commit, notice e transitive dependencies prima di ogni copia; GPL/AGPL/LGPL, source-available e asset con vincoli sono distinti. Non aggiungere dipendenze né token segreti in questo step.
