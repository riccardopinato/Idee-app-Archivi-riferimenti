# CAP-0185 — Licenze e dipendenze

Ricerca funzionale E0: nessuna licenza conferisce qui una autorizzazione automatica di riuso commerciale del codice.

## Fonti e classificazione disponibile
- appwrite/appwrite: REST BSD-3-Clause; license per source file must be independently verified
- taskade/taskade: DOCUMENTATION_REFERENCE_ONLY: Repository di documentazione e press kit, senza codice del prodotto; testi consultabili/citabili con attribuzione, media e marchio protetti
- silverbulletmd/silverbullet: REST MIT; license per source file must be independently verified
- tldraw/tldraw: RESTRICTED_SOURCE_AVAILABLE: Licenza tldraw custom: uso development; deploy produzione richiede licenza trial/commerciale specifica
- xyflow/xyflow: REST MIT; license per source file must be independently verified
- baserow/baserow: PERMISSIVE_SCOPED: MIT per Open Source Edition; docs CC-BY-SA; premium/enterprise con licenze separate
- seatable/seatable: LICENSE_NOT_CLEAR_AT_THIS_REPO: README descrive dtable-web ed eventi Apache-2.0, seaf-server AGPL-3.0, dtable-server proprietario; repository indice senza license root

Verificare file, directory, commit, notice e transitive dependencies prima di ogni copia; GPL/AGPL/LGPL, source-available e asset con vincoli sono distinti. Non aggiungere dipendenze né token segreti in questo step.
