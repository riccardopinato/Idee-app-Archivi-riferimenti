# CAP-0110 — Avvio guidato micro-passo e focus breve

**KIT LIVELLO 1: RIFERIMENTI_ACQUISITI.** Non implica codice estratto o testato.

## Funzionalità

Ridurre volontariamente una task complessa a un primo passo piccolo e avviare una sessione focus breve, senza cambiare la task originaria.
