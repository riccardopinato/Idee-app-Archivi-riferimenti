# CAP-0173 — Licenze e dipendenze

Ricerca funzionale E0: nessuna licenza conferisce qui una autorizzazione automatica di riuso commerciale del codice.

## Fonti e classificazione disponibile
- makeplane/plane: REST AGPL-3.0; license per source file must be independently verified
- opf/openproject: REST GPL-3.0; license per source file must be independently verified

Verificare file, directory, commit, notice e transitive dependencies prima di ogni copia; GPL/AGPL/LGPL, source-available e asset con vincoli sono distinti. Non aggiungere dipendenze né token segreti in questo step.
