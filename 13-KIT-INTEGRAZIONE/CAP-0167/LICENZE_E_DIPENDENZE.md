# CAP-0167 — Licenze e dipendenze

Ricerca funzionale E0: nessuna licenza conferisce qui una autorizzazione automatica di riuso commerciale del codice.

## Fonti e classificazione disponibile
- anyproto/anytype-ts: RESTRICTED_SOURCE_AVAILABLE: Any Source Available License 1.0: uso non commerciale o commercialità limitata alle Allowed Networks
- memrynote/memry: REST AGPL-3.0; license per source file must be independently verified
- cryptpad/cryptpad: REST AGPL-3.0; license per source file must be independently verified
- amark/gun: PERMISSIVE_SCOPED: Testo LICENSE.md include licenze permissive di componenti, fra cui MIT e Apache-2.0
- yjs/yjs: PERMISSIVE_SCOPED: MIT
- automerge/automerge: REST MIT; license per source file must be independently verified

Verificare file, directory, commit, notice e transitive dependencies prima di ogni copia; GPL/AGPL/LGPL, source-available e asset con vincoli sono distinti. Non aggiungere dipendenze né token segreti in questo step.
