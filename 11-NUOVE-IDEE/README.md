# Nuove idee — area dedicata

Questa cartella raccoglie **solo le idee ancora in valutazione**, separate dal catalogo delle app già registrate in [01-PORTAFOGLIO](../01-PORTAFOGLIO/CATALOGO_APP.md).

## Dove scrivere

- **[INBOX_IDEE.md](INBOX_IDEE.md)** — elenco unico delle nuove proposte, anche incomplete; conservarle senza eliminarle.
- **[Template scheda app](../10-MODELLI/SCHEDA_APP.md)** — per approfondire una candidata prima di decidere lo sviluppo.
- Le nuove classifiche di idee candidate possono essere aggiunte in questa cartella con data e criteri; la classifica dei prodotti attivi resta nel portafoglio.

## Ciclo di vita

`PROPOSTA → ANALISI → VALIDAZIONE → APPROVATA / RINVIATA / SCARTATA → (eventuale) PORTAFOGLIO`

Anche le idee **scartate o rinviate** rimangono visibili con motivazione e data. La promozione non elimina la proposta: il record conserva un collegamento alla scheda canonica del prodotto.

**Importante:** non considerare `candidato` equivalente a `mai sviluppato`; verificare l'eventuale repository o donor prima di affermarlo.
